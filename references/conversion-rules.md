# 甲方稿 → 制作版 转换规则

> 用户接到原始稿后，skill 要做 4 件事：补元数据、拆镜、补镜头设计、补备注。本文档是判断标准。

## 一、识别原始稿类型

根据用户贴的内容，先判断是哪种类型：

| 类型 | 信号 | 处理 |
|---|---|---|
| **docx 自由文本** | 没有表格、连续段落、【第一幕】/【XX 场景】 | 拆幕 + 拆镜 |
| **docx 表格** | 有 `序号`/`画面`/`字幕` 列 | 直接复用列，补列即可 |
| **xlsx** | 工作表形式 | 读取后判断是否已经是制作版 |
| **纯文本** | 用户贴一段故事 / 需求 / 会议纪要 | 按叙事节奏推断幕与镜 |
| **已是制作版** | 已有 `镜号` 列 + 信息头 | 提示用户，不做转换 |

## 二、判断要不要"拆镜"

**核心原则：1 个镜头 = 1 个完整动作或 1 段完整对话。**

需要拆的情况：
- 同一段落里景别突变（`特写钱袋子... 主角拿起来挂在脖子上... 笑的幸福感满满` → 拆 2-3 镜）
- 同一段落里场景突变（`主角走在路上... 突然进入银行大厅` → 拆 2 镜）
- 对话超过 3 句不切换机位（按角色/机位拆）
- 复合动作超过 3 个独立动作

**不需要拆的情况：**
- 短片（<10 镜）：宁粗勿细，1 段描述 = 1 镜
- 用户明确说"一镜到底"
- 转场镜头（黑幕、定格）

## 三、判断要不要"补镜头设计"

镜头设计 = 景别 + 运镜 + 补充镜头。

- **如果原始稿写明景别**（"特写钱袋子"、"广角仰拍主角"）→ 直接填入
- **如果原始稿只有动作**（"我翻材料的手突然停住"）→ 根据内容推断：
  - 手部动作 → `特写` / `近景手持`
  - 表情变化 → `中近景胸部以上 + 面部特写`
  - 走路 / 移动 → `跟拍` / `手持跟拍`
  - 远景人物 → `大景入画背影`
- **完全无法判断** → 填 `待定`

参考 `示例脚本 A（金标准）.xlsx` 的镜头设计列作为风格基准。

## 四、判断要不要"补备注"

按以下优先级给备注填值：

1. **合规 / 风险提示**（银行/政企客户最优先）：
   - 关键词：合同、签字、空白凭证、印章、章
   - 例：`合同和笔需提前准备` / `重空未上锁，心存侥幸`
2. **道具准备**：
   - 例：`需要一位群演（群演建议是放得开的大叔）和门店` / `道具准备：家庭教育类的书籍`
3. **拍摄时间 / 补拍**：
   - 例：`白天镜头需要先拍` / `周一补拍` / `6号上午`
4. **特殊效果**：
   - 例：`色调急转：暖金 → 冷蓝灰` / `AIGC叠化` / `面部特写锁定表情`
5. **演员 / 群演**：
   - 例：`柜面组` / `客户经理组` / `人力` / `小企业部`
6. **空镜 / 画面预留**：
   - 例：`右边区域留白可加字幕` / `人物占画面二分之一`

## 五、判断要不要"加幕"

加幕的判定：

| 镜数 | 是否加幕 |
|---|---|
| < 8 镜 | 不加（单线短片） |
| 8-15 镜 | 可加可不加，看叙事是否有清晰分段 |
| 15-30 镜 | **必须加**，按场景或剧情阶段分 |
| > 30 镜 | 必须加，每幕 5-10 镜，标 3-5 幕 |

幕标题选择：
- 默认：`第一幕` / `第二幕` / `第三幕` / `第四幕`
- 数字命名：`1:引入篇` / `2:成长篇`（十周年行庆风格）
- 篇章命名：`【篇章一】糖画` / `【篇章二】月饼`（某非遗纪录片风格）
- 双线标记：`【救赎线A】` / `【深渊线B】`（禁毒 V2 风格）

→ **沿用用户原稿的命名风格**。如果用户原稿里完全没有幕标记，**不强行加**，除非镜数 > 15。

## 六、信息头填写

| 字段 | 填写规则 | 兜底值 |
|---|---|---|
| 视频名称 | 从原始稿标题提取 | 用户原始稿第一段 |
| 视频主题 | 原始稿里的"主题"或推断 | 留空（让用户填） |
| 拍摄时间 | 用户指定；不指定则留空 | 留空 |
| 截止时间 | 用户指定 | 留空 |
| 镜号数 | 算一遍 = 幕外镜头总数 | 自动算 |
| 拍摄道具 | 汇总所有"道具"列内容，去重 | 留空 |
| 主要产品 | 银行/政企客户产品名 | 留空 |
| 时间进度 | 默认 0 | 0 |
| 完成镜号 | 默认 0 | 0 |
| 完成进度 | 默认 0 | 0 |

## 七、风格细节

- **画面内容**用第一人称"我"：参考 `示例脚本 A（金标准）.xlsx`
- **台词**用角色名 + 冒号：`主持人：` / `主角：` / `张大哥：`
- **内心独白**加前缀：`内心独白（画外音）：` 或 `内心：`
- **音效**简短：`电话铃声骤起` / `滑稽卡通音效`
- **禁止**用"…"做省略号，用"……"中文省略号
- **禁止**用空格做对齐，用全角标点

## 八、常见错误规避

| 错误 | 正确做法 |
|---|---|
| 把景别写进"画面内容"列 | 景别放"镜头设计"列 |
| 把"待定"当万能占位填到所有镜头 | 只在无法判断时填"待定"，其他时候尽力推断 |
| 把多个场景硬塞进一个镜头 | 跨场景必须拆镜 |
| 用 `画面1/画面2` 编号 | 用"镜号"列，从 1 开始递增 |
| 忘加幕结构 | 镜数 > 15 必加 |
| 把所有台词都标"主角" | 区分角色名 |

## 九、旁白拆分规则（核心铁律）

原稿旁白**一字不改**全部加入「台词/旁白」列，只做分段，不做改写。

**按语义分段**：把整段旁白拆成自然语义小段，每段独立填入一格，与对应画面一一匹配。

错误示例（整段堆叠 + 后续标"同旁白"）：

```
镜10 | 画面：餐厅日常 | 台词：近年来，永嘉县岩头镇大力推进青年乡创与共富工坊建设，吸引一大批青年回乡干事创业。如今已孵化青年乡创项目10个，带动400多人就地就业，农户每月可实现增收近千元。
镜11 | 画面：咖啡营地 | 台词：（同旁白）
镜12 | 画面：市集日常 | 台词：（同旁白）
```

正确示例（分段匹配）：

```
镜10 | 画面：餐厅日常，服务员穿梭、食客落座、菜品上桌 | 台词：近年来，永嘉县岩头镇大力推进青年乡创与共富工坊建设，吸引一大批青年回乡干事创业。
镜11 | 画面：咖啡营地，游客落座景观位、游客互动 | 台词：如今已孵化青年乡创项目10个，带动400多人就地就业。
镜12 | 画面：市集日常，摊主讲解、游客挑选 | 台词：农户每月可实现增收近千元。
```

## 十、画面内容写法

写「到现场需要拍什么」的具体动作/内容清单，摄影师照着就能拍。

- ✅ 正确：`工作人员给大学生讲解政策，几人实地踏勘场景，对着房屋结构指指点点，办公楼和丽水街店面改造前后对比`
- ❌ 错误（冗词）：`工作人员给大学生讲解政策一组镜头，几人实地踏勘场景一组镜头`（"一组镜头"四个字没有必要）
- ❌ 错误（文学化）：`充满了蓬勃朝气的青年创业者们，在山水之间挥洒汗水`（摄影师没法照着拍）

## 十一、口播/采访类台词标注

- 受访者口播类镜头，备注列固定标注：`受访者自由发挥，我方文案仅供参考`
- 台词/旁白列只放参考稿原文，不替代受访者的实际表达
- 固定机位采访可拆多镜（前半段/后半段），机位保持一致

## 十二、采访提问稿（只有提问、没有答案）

典型形态：甲方给一份「提问清单」，每个问题后带括号说明期望受访者讲的方向，但**没有写台词**。

例：

```
1、你以前是老师，为什么愿意离开讲台，当"某项目负责人"呢？
（可以讲述当年有 200 多个人一起竞争，你觉得自己凭什么是被选上的那一个？）
```

**绝对禁止替受访者编造回答。** 按每个问题拆成 2-3 镜：

| 镜位 | 画面内容 | 台词/旁白 | 备注 |
|---|---|---|---|
| 提问镜 | 提问者面向受访者发问 | 提问原话（一字不改） | 提问要给足停顿留白，方便后期插空镜 |
| 回答镜 | 受访者讲述 | `【口播提示】<把括号里的方向搬过来>` | `受访者自由发挥，我方文案仅供参考`；追问具体人名/数字，便于后期配画面 |
| 空镜（可选） | 按提示方向能拍到的现场画面 | `（无台词，留同期声）` | 需协调的档期、群演、授权 |

**`【口播提示】` 是给摄制组和受访者的提词方向，不是台词脚本**，后期按实际口播重新字幕。

## 十三、A-roll / B-roll 结构（访谈片的默认做法）

用户接到访谈类需求时，**默认按 A-roll + B-roll 拆**，不要假设问答画面在外景。

- **A-roll**：室内固定场景、固定机位录全部对话，声音以同期声为准。提问与回答都在同一机位解决，不换景、不为"动作"另摆机位。
- **B-roll**：外景补拍的**无声**画面，后期铺在 A-roll 的同期声上。

拆镜规则：

| 镜位 | 拍摄地点 | 画面内容 | 台词/旁白 | 备注开头 |
|---|---|---|---|---|
| 定场镜（每片 1 条） | 室内采访区 | 布光到位、对坐座位建立、桌上道具 | `（无台词，留环境声）` | `A-roll 定场镜` |
| 提问镜 | 室内采访区 | `固定机位：<谁转向谁提问 + 动作>` | 提问原话 | `A-roll 主录` |
| 回答镜 | 室内采访区 | `固定机位：<受访者看向提问者作答 + 动作>` | `【口播提示】…` | `A-roll 主录；受访者自由发挥…` |
| B-roll 镜 | 外景 | 按同期声内容能拍到的现场画面 | `（B-roll 无声画面，配 XX 镜同期声）` | `B-roll：按 XX 镜「…」同期声补拍` |

要点：

- A-roll 的「镜头设计」统一写 `中景/中近景固定（主机位）+ 副机位侧面一条`，并注明"情绪特写由后期裁切，不另摆机位"
- A-roll 全程连续录制不喊停，备注提醒双机位 + 单独挑杆麦收音
- B-roll 不配音、不留台词，音效列留空（声音全部来自 A-roll 同期声）
- **开场与结尾通常例外**：用户会明确说"结尾例外"，此时外景部分照原稿走，不要套 A-roll
- 幕名可标注结构，例：`【第三幕】访谈·为什么是她（Q1-Q3）｜室内 A-roll + 外景 B-roll`

- 虚拟/AI 提问角色（如某 IP 配音提问）要在备注写清：后期合成、现场必须预留构图和留白
- 引用第三方素材（央视画面、受访者已有短视频）必须在备注标授权归属
- 涉及金额、村民收入、订单数据的画面，备注要标核实与隐私要求

## 十四、数据与时令信息点的写法

原稿或客户资料里的**数字、规模、时令**不要在镜头前干念——没人会在镜头前报"这片熟了两万株""月营收 120 万"。

落地办法：把数字挂在角色的**动作和处境**上，让它变成一句体感话。

| 资料写的 | 别这样念 | 改成 |
|---|---|---|
| 某作物成熟 2 万株、正值当季 | "这一片熟了两万株，正是当季" | 角色边收边答："今年这一片都熟了，得赶在霜前收完。" |
| 经营面积 800 平、30 桌 | "800 平，大小桌 30 张" | "这一桌摆得下整场聚会。" |
| 半年建成 | "180 天就建成了" | "去年这时候还是工地，过完年就开街了。" |
| 日均客流 200 人次 | "日均客流 200" | "周一中午包厢都满了。" |

同时遵守：

- **时令要落到画面上**——"正值当季"要拍出当季的物证（作物上的白霜、断口的汁水、正在收的动作），不能只在台词里说
- **数字本身不丢**——如果客户坚持要出现，放在字幕花字里，不要让人物念出来
- **信息点优先挂在最有动作感的那一个镜**，不要每个镜都提一遍


## 十五、人物无法到场时的形式转译（前移式改造）

**触发**：某角色因档期 / 权限 / 场地原因不能到某个拍摄现场，但可以在棚里或办公室出镜。

**错误做法**：把这个角色的现场台词直接删掉。品牌来历、门店知识、专业背景这类信息会随之丢失，脚本立刻变薄。

**正确做法：前移**。

1. 把该角色**所有的介绍性台词**挪到他能去的场景（通常是办公室 / 棚），集中讲完
2. 给他一个"为什么不去现场"的理由，一句话交代即可
3. 现场镜改为单人：自述 / 对镜头说话 / 与现场人员交流
4. 现场的验证性信息用**现场收音**（对方不入镜）解决；不替受访者预设答案

**最优落点**：让原有的"回收镜"兼任下一站的交代。探店 / 测评类片子每站之后通常有一个回到主场的回收镜，把下一站的知识讲解放进这一镜，就不需要新增镜号。

**收益**

- 该角色全部场次集中在同一地点，可一次连拍，排期成本骤降
- 叙事反而更紧：先讲门道 → 去现场验证 → 回来汇报
- 观众不会问"那个人怎么没跟着来"

**改完必须校验**：遍历所有非该场景的镜，检查是否残留该角色的发言。
注意区分 `角色：`（真发言，必须清）与 `角色说 / 角色交代`（他人转述，允许保留）。
用正则扫一遍即可，比肉眼快且不会漏。

**前移之后必须做去重巡检（配套本节，最容易翻车的一步）**

台词一前移，同一知识点就会在两处各留一份：办公室讲过一遍，现场角色又复述一遍。**第二次必须改成"验证句"，不能是"复述句"。**

判断准则：**画面能看见的信息，删掉办公室的预告，留给现场亲眼发现；画面看不见的幕后与来历（跑码头收货、品牌字号来历），保留在办公室，现场只用一句''果然是这样''去验证。**

自检办法：改动完成后，把每个信息点在台词里全文搜一遍，出现两次的必须二选一——

- ❌ 办公室："门口有免费茶，墙上挂着老秤" + 现场："主持人说门口有免费茶，这是十六两的老秤"
- ✅ 办公室："今天给你介绍第一顿便饭，这家店" + 现场："真有这桶茶，我试了"

用户真实取舍倾向：**宁可让办公室那句变薄**。亲眼验证有悬念，提前告知是剧透。

**双轨产出**：用户常说"原版保留、另出新版"。此时**不要回改原版**，即使发现原版有错别字，也只在回复里告知，由用户决定。


## 十七、二次加工的三处技术坑（插镜 / 移动 / 重排必读）

本节配套「路径 B：dump 重建」。这三处都不是创意问题，纯粹是操作失误，
但每一处都会让整理好的稿子在最后一步出错，且**报错信息看不出真正原因**。

### 坑 1 · 幕名里的镜号范围有两种写法

幕的镜号范围既可能是多镜 `（镜 4-8）`，也可能是单镜 `（镜 15）`。
用 `（镜 \d+-\d+）` 去匹配，**单镜幕匹配不到，会变成叠加双括号**——
实际出过 `…（镜 13）（镜 15-15）` 这种肉眼一看就知道坏了的幕名。

正确正则：`（镜 [\d\-]+）`，两种都能兜住。
重新写范围时还要注意：**单镜幕输出 `（镜 15）`，不要输出 `（镜 15-15）`**。

### 坑 2 · 插镜之后，校验用的镜号必须跟着位移

插入 N 镜后，插入点之后的所有镜号整体 +N（多个插入点则累加）。
**校验脚本里写死的镜号检查点也要跟着位移**，否则内容明明保留完好，
脚本却报"改动丢失"，害得人白白回头去查。

实际踩过：一次 +2 位移后，检查点仍按旧镜号查，误报两处内容丢失；
按重排后的映射复核，内容全在（原镜 10、11 → 新镜 12、13）。

**做法**：先算出一张「旧镜号 → 新镜号」映射表，打印出来核对一遍，
再拿这张表去校验。**不要凭记忆写死镜号。**

### 坑 3 · 动手改之前，先 diff 回读

用户把改过的 xlsx 交回来时，**先用脚本逐格 diff 自己的上一版和他的版本**，
把改动明细打印出来看一遍再动手。原因有两个：

1. 用户清空某一列往往是有意的——他删掉的既是内容也是意图（见「改稿回流」），误判会把它们重新填回去
2. **用户的改动往往高度同向**，一眼能读出他真正的取舍准则——
   例如一次 8 处改动全是"删重复"，顺着这个方向读，能提炼出下一次通用的规则

改完之后同样要 diff 一遍自己的产出 vs 用户版本，确认该保留的一处没丢。
