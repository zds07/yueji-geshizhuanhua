# 短视频分镜脚本格式规范

> 本规范以 `示例脚本 A（金标准）.xlsx` 为金标准，从用户提供的 11 个参考脚本中提取。所有 xlsx 制作版输出必须严格遵循本规范。

## 一、文档级元数据

### 1.1 文件格式

- 强制使用 `.xlsx`（不用 `.xls`、不用 `.docx` 表格）
- 工作表名：`Sheet1`（默认即可，不修改）
- 起始版本用 `Sheet1`，扩展材料放 `Sheet2` / `Sheet3`（常为空）

### 1.2 字体

- 全表统一使用 **微软雅黑**（Microsoft YaHei）
- 标题字号：**24**（A2 / B2 单元格）
- 信息头字号：**12**（C4 - C9, I6, M6, C7-C9, I7 等）
- 表头字号：**12**（B11 整行）
- 镜头描述字号：默认（约 11）

### 1.3 颜色（一比一复刻金标准）

- 标题 / 信息头标签 / 表头底色：**`#383838`**（深灰，白字）
- 幕标题行底色：**`#D9EAD3`**（浅绿，黑字）
- 镜头描述行：**白底 / `#F3F3F3` 交替**（黑字）
- 默认不使用绿色主题；如用户特别要求绿色，通过 `theme_color` 参数覆盖

### 1.4 边框 / 对齐

- 全表细线边框（默认）
- 信息头单元格：水平居中 + 垂直居中
- 镜头描述单元格：左对齐 + 顶部对齐 + 自动换行

## 二、信息头（行 1-10）

固定 7 行结构，所有 xlsx 制作版都按此填写：

| 行 | 位置 | 内容 | 示例 |
|---|---|---|---|
| 1 | A1 横跨 | `短视频拍摄脚本`（大标题） | 24 号加粗 + 灰底 |
| 2 | B2 - C2 标签 / D2 填值 | `视频名称` | "客户经理金标准脚本的一天" |
| 3 | B3 - C3 标签 / D3 填值 | `视频主题` | "重空管理/合规反诈" |
| 4 | C4 / D4 / E4-H4 / I4-K4 / M4 / N4-P4 | `拍摄时间` / 填值 / `截止时间` / 填值 / `镜号数` / 填值 | "2025-02-18" / "2025-02-21" / 19 |
| 5 | C5 / D5 / E5-G5 / H5 / I5-K5 | `拍摄道具` / 填值 / `主要产品` / 填值 | "公文包、PAD、空白借记卡" / "示例项目" |
| 6 | C6 / D6 / E6-G6 / H6 / I6-K6 / M6 / N6-O6 | `时间进度` / 填值 / `完成镜号` / 填值 / `完成进度` / 填值 | "0" / "0" / "0" |
| 7-9 | C7-C9 / D7-D9 / I7-I9 | 留白（拍摄时间截止时间留空） | |
| 10 | 整行 | 空行（表头前的缓冲） | |

**合并规则：**
- B2:P2 = 合并（标题行横跨）
- B11:P11 = 合并（表头行横跨）
- C4:D4 = 合并（"拍摄时间"标签横跨）
- D4 单独 = "拍摄时间"标签
- E4:H4 = 合并（拍摄时间填写区）
- I4:K4 = 合并（"截止时间"标签区）
- L4 单 = "截止时间"标签
- M4 单独 = 截止时间值
- N4:P4 = 合并（镜号数标签区）

> 实际生产中不需要逐格按合并写——直接调 `scripts/build_xlsx.py`，脚本已固化了合并规则。

## 三、表头（行 11）

10 列固定，顺序不可调换：

```
| 镜号 | (空) | 拍摄地点 | 画面内容 | (空) | 镜头设计 | 台词/字幕 | (空) | 时长 | 备注 | 道具 | 音效 | 参考画面 |
```

**列宽（字符数）：**

| 列 | 列名 | 宽度 | 用途 |
|---|---|---|---|
| A | 镜号 | 3.0 | 数字（如 1, 2, 3） |
| B | (空) | 1.8 | 间隙 |
| C | 拍摄地点 | 9.6 | 短文本（"办公室"、"分行楼下小公园"） |
| D | 画面内容 | 12.3 | 第二段（与 E 列拼合） |
| E | 画面内容 | 10.2 | 第一段（与 D 列拼合） |
| F | 镜头设计 | 27.5 | 长文本（"中景固定 + 过肩镜头看到对面表情"） |
| G | 台词/字幕 | 25.2 | 长文本（演员台词/内心独白/画外音） |
| H | (空) | 13.9 | 间隙 |
| I | 时长 | 19.8 | "5s" / "10s" |
| J | 备注 | 10.2 | 导演提示 / 合规要点 |
| K | (空) | - | 间隙 |
| L | 参考画面 | 33.6 | 留空（用户后续填图） |
| M | 道具 | 18.5 | 短文本 |
| N | 音效 | 10.2 | 短文本 |
| O | (空) | - | 间隙 |
| P | 参考画面 | 15.1 | 留空（用户后续填图） |

> **D 和 E 实际是同一列"画面内容"的左右两半**——为了内容能自动换行展开，会拆成两个 12 字符的列合并填。生产时不需要手算，脚本自动合并。

## 四、镜头行（行 12 起）

### 4.1 幕结构（行 12, 21, 27, 31 等）

长片（>15 镜）必须有 **幕** 作为分割行，格式：

- 整行 B:P 合并
- 内容：`第一幕` / `第二幕` / `第三幕` / `第四幕`
- 加粗 + 灰底 + 居中
- 幕行的"镜号"列空

变体（用户曾用过的）：
- "1:引入篇" / "2:成长篇" / "3:回忆篇" / "4:升华篇"（十周年行庆）
- "【篇章一】糖画" / "【篇章二】月饼"（某非遗纪录片）
- "【救赎线A】" / "【深渊线B】"（禁毒 V2 双线）

→ 如果用户原始稿用了其他幕标题，**沿用**而不强制改为"第一幕"。

### 4.2 镜头编号

- 整数递增（1, 2, 3, ...）
- 幕行不占镜号
- 同一镜头如果跨多行（拆得太细），下一行镜号留空
- 单线短片可省略幕行，但镜号必须连续

### 4.3 拍摄地点

- 用**场景名**，不用具体描述
- 例：`办公室` / `工位` / `分行楼下小公园` / `会议室` / `二楼会议室`
- 同一场景下，多个镜头的拍摄地点填同一个词，**不要重复写**
- 如果同一场景有多个角度：可在地点后加括号区分（`办公室（工位）` / `办公室（门口）`）

### 4.4 画面内容

- **第一人称** "我" 描述动作
- 用连续动作的复合描述（一句 = 1 个镜头的所有内容）
- 多动作用句号或分号分隔
- 例：`我拎着公文包走进办公区，洋溢着自信笑容，脚步轻快走向自己工位`
- 例：`我翻材料的手突然停住，眉头皱起来，表情一僵`
- **不要**写"特写：xx"或"中景：xx"（这些放"镜头设计"列）

### 4.5 镜头设计

格式：`景别 + 运镜 + 补充`

- **景别**：大景 / 中景 / 近景 / 特写 / 过肩镜头
- **运镜**：固定 / 摇 / 推 / 拉 / 移 / 跟拍 / 手持 / 主观视角
- **补充**：分镜的额外镜头（"补充单独面部特写和脚步"）

例：
- `镜头从办公室拐角处开始，随着脚步摇到面部特写。补充单独面部特写和脚步`
- `中近景把手持钥匙插入锁孔的动作连贯拍下，特写锁孔的钥匙`
- `广角仰拍主角，挤进去后展开对话；俯拍黑衣人高举传单说话`

如果一时无法确定，用占位 `待定`（用户会后续补）。

### 4.6 台词/字幕

三种类型，用前缀区分：

| 类型 | 前缀 | 例 |
|---|---|---|
| 演员台词 | `角色名：` 或 `主角：` | `主持人：上班啊，替你们做旅行推荐官呢` |
| 内心独白 | `内心独白（画外音）：` | `内心独白（画外音）："一会就回来，不会有事儿的"` |
| 画外音 | `（画外音）` | `（画外音，冷硬）："这里是信贷作业中心"` |
| 画面字幕 | 直接写文字 | `画面定格 + 红字：重要空白凭证未入柜上锁` |
| 同期声 | `【同期声】` | `【同期声】兽医："怎么伤成这样，得赶快抢救了！"` |
| 电话/广播 | `（电话铃音骤起）` | （音效提示） |

多角色对话分行写：
```
主持人：上班啊，替你们做旅行推荐官呢。
角色 C：主持人，今天不上班？
```

### 4.7 时长

- 短片（30s 内）："3s" / "5s" / "10s"
- 长片：用区间 `"10s (0:00-0:10)"`（脚本 7-28 风格）
- 精确到秒

### 4.8 备注

- 导演提示：`特写锁定表情` / `面部特写`
- 合规要点：`重空未上锁，心存侥幸` / `合同和笔需提前准备`
- 制作提示：`需要一位群演（群演建议是放得开的大叔）和门店` / `用已有的真实视频，暖金色调`
- 拍摄提示：`白天镜头需要先拍` / `周一补拍`
- 空镜预留：`右边区域留白可加字幕` / `人物占画面二分之一，上面二分之一预留文字位置`

### 4.9 道具 / 音效

- 道具：逗号分隔，`U盘、干净的工位`
- 音效：直接写效果，`滑稽卡通音效` / `心跳、紧张、上升音效` / `电话铃声骤起`

### 4.10 参考画面

- 大多数情况留空
- 填法：贴参考图 / 写 `（参考网上）` / 写 `网络素材`

## 五、行高规则

| 行类型 | 默认行高 |
|---|---|
| 第 1 行（标题上方） | 6.0 |
| 第 2 行（"短视频拍摄脚本"） | 45.0 |
| 第 3 行（视频名称/主题） | 14.0 |
| 第 4-9 行（信息头） | 28.0 |
| 第 10 行（表头前缓冲） | 17.0 |
| 第 11 行（表头） | 33.0 |
| 镜头行 | 80.0 - 200.0（按内容长度自动） |
| 长镜头行（如台词密集） | 200.0 - 300.0 |
| 幕行 | 80.0 - 90.0 |

脚本自动按内容长度估算行高。

## 六、合并单元格规则

每个信息头标签列需要水平合并（例如 `C5:D5` = "拍摄道具"），但实际生产中**直接调脚本**，不需要手算。

## 七、视觉风格总结

- **极简 + 工业风**：微软雅黑 + 灰底 + 大量留白
- **镜头密集**：平均每行高度 80-150 字符，能装下完整镜头描述
- **导演导向**：备注列密度高，几乎每行都有提示
- **不花哨**：没有配色、没有图标、没有截图框（参考画面列也是纯文本占位）

## 八、v2 紧凑列结构（当前实际标准）

> v2 起以「紧凑合并列」为统一标准：删除所有空白缓冲列，相邻功能列合并显示，全表文字居中，横向 A3 打印。

### 8.1 列结构（17 物理列合并为 10 逻辑列）

```
A:左缓冲(4) | B:镜号(5) | C:D=拍摄地点(8+8) | E:F=画面内容(10+10) |
G:H=镜头设计(15+15) | I:K=台词/旁白(10+10+10) | L:时长(9) | M:备注(12) |
N:道具(10) | O:音效(10) | P:Q=参考画面(10+10)
```

### 8.2 视觉规则

- 全表文字**居中对齐**（水平 + 垂直 + 自动换行）
- 镜头行绿白交替：偶数镜行白色，奇数镜行浅绿（默认 #D9EAD3 系）
- 幕标题行：浅绿底色横跨全表

### 8.3 打印设置（必须固化）

| 项 | 值 |
|---|---|
| 方向 | 横向（landscape） |
| 纸张 | A3 |
| 缩放 | 适合一页（fitToWidth=1, fitToHeight=1） |
| 打印居中 | 水平居中 |
| 页边距 | 上下 0.5 / 左右 0.4 / 页眉页脚 0.3 |
| 冻结窗格 | 不冻结（保证滚动自由） |

### 8.4 信息头新增字段

在固定 7 行信息头基础上，增加：
- 视频主题列含"主题关键词"提取（第一段旁白前 40 字）
- 拍摄道具列含"现场可复用道具"标注（如工牌、招牌）
- 备注/道具/音效列自动填充：根据画面内容推断，需人工复核

## 九、与"甲方稿"的差异

甲方稿（`2.17钱袋守护者.docx`）特征：
- 自由文本，无表格
- 用【开场】/【第一幕】做幕标记
- 场景/镜头/台词分块写
- 没有拍摄时间/道具/镜号数等元数据

→ 制作版必须**补全**这些元数据，**拆分**粗粒度场景为细粒度镜头，**添加**镜头设计与备注列。
