## 关键观察

### 制作版 xlsx 共有的元数据

所有 xlsx 制作版都有这 7 行信息头（无论完整度）：

```
短视频拍摄脚本
视频名称
视频主题
拍摄时间 | 截止时间 | 镜号数
拍摄道具 | 主要产品
时间进度 | 完成镜号 | 完成进度
（表头前的空行）
```

→ 这是固定结构，不能省。

### 列结构的核心四列

**所有变体都保留**这 4 列：

- 镜号（或 序号）
- 拍摄地点（或 场景）
- 画面内容（或 画面、画面描述）
- 字幕 / 台词 / 旁白

→ 即使原稿件列结构不同，制作版必须保证这 4 列存在。

### 镜头设计列的演进

- 早期（v1 / v2 / v5）：**无"镜头设计"列**，景别写在"画面内容"里
- 进阶（v3）：**"分镜画面"列** 与"画面内容"分离
- 稳定（金标准 v）：**"镜头设计"列** 独立存在，景别+运镜+补充镜头

→ 制作版输出**优先使用"镜头设计"列**，但如果原稿里没有景别信息，可以不填或填"待定"。

### 幕标题的 4 种风格

- 序数：`第一幕 / 第二幕 / 第三幕`（最常见，金标准）
- 数字命名：`1:引入篇 / 2:成长篇`（周年庆题材常用）
- 篇章：`【篇章一】xxx / 【篇章二】xxx`（传统手艺类）
- 双线：`【线A】 / 【线B】`（对比叙事类）

→ 沿用原稿风格，不强行改写。

### 角色命名约定

- **主角台词用角色名 + 冒号**：`主持人：` / `主角：` / `张大爷：` 等，**不要都用"我"**
- 行业客户题材按实际身份命名（如项目负责人、柜面人员、客户经理）
- 多人纪录片 / 访谈片**不用"我"**，统一写角色名——否则摄制组无法执行

### 镜头描述的两种视角

- **第一人称"我"**：金标准风格，适合叙事型短片
- **第三人称"主角"**：旧格式原始稿风格，适合群像型短片

→ 默认用第一人称"我"，但当镜头里有多个角色对话时，对话方用角色名。

### 时长的两种格式

- 短格式：`5s` / `10s`
- 长格式：`10s (0:00-0:10)`（长片用）

→ 镜数 > 30 用长格式，否则短格式。

### 道具 / 演员列

- 道具列：所有变体都有
- 演员列：进阶变体独有（按组别划分）
- 群演标注：写在备注列（`需要一位群演（建议形象贴合角色的中青年）`）

→ 演员列**可选**。如果指定了演员，加入"演员"列；否则省略。

### 备注列的密度

几乎所有镜头行都有备注。备注的优先级（从高到低）：

1. 合规 / 风险提示（行业客户类必备）
2. 道具准备 / 群演需求
3. 拍摄时间 / 补拍提示
4. 演员组别分配
5. 特殊效果 / 调色 / 转场
6. 空镜预留 / 文字位置

→ 镜数 > 10 时，备注列每行必填。

## 制作版 v.s. 原始稿的判断标准

看到一份文件，**最快判断**它是不是制作版：

| 特征 | 原始稿 | 制作版 |
|---|---|---|
| 媒介 | docx 自由文本 或 docx 简单表格 | xlsx |
| 信息头 | 无 | 有"短视频拍摄脚本"+ 6 行元数据 |
| 镜号 | 用 `01 / 02` 或【第N幕】 | 用整数 `1 / 2 / 3`，带"镜号"列 |
| 镜头设计 | 偶尔写在画面里 | 独立列 |
| 备注 | 无 | 每行都有 |
| 道具 | 偶尔提到 | 独立列 |
| 演员 | 偶尔提到 | 独立列（可选） |

→ 制作版的所有特征都是"有"；原始稿都是"无"或"偶尔"。

## 兜底策略

拿到一份输入，不知道该走哪条路径时：

1. **有 7 行信息头 + 镜号列 + 镜头设计列 + 备注列** → 已是金标准格式，直接复用
2. **有信息头 + 镜号列 + 备注列 + 道具列，但无镜头设计列** → 升级到金标准（补镜头设计）
3. **有镜号/序号列 + 简单列** → 极简版路线（按 6 列骨架补到标准 10 列）
4. **docx 自由文本** → 补元数据 + 拆镜
5. **docx 表格** → 列差异不大时直接补列
6. **纯文本 / 会议纪要 / 需求** → 按叙事节奏推断幕与镜，信息头全部留空让用户填
